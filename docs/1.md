0. furter keep in mind that we access to all ssh servers as root and have root privileges
1. Its a synchronizer of my folders via rsync. better to use python rsync libs. It should syncronize local files on remote ssh servers
2. ssh server could be accessible using using one of following options:
   2.1. ssh key
   2.2. name + password 
3. rsync-ed files should be stored in specified folders. let’s tentatively call it `Private`
4. on ssh server files could be stored in 2 ways:
   4.1 as is
   4.2 encoded using `mount -t ecryptfs ~/Private/ ~/Private` (if we dest name is ~/Private )
       in this case we need to check if this destination folder is mounted (its decrypted and mounted already). If not - just mount it.
       and also after rsync we need unmont it (encrypt back again)
5. so config file for should look like that:
   for every local folder it could have several configured ssh destinations (we need duplicate our copies for safety):
     every ssh-destination have the following description:
       5.1 ssh name or ip
       5.2 private folder for storing destination folder. for example its could be `/root/Private`. its the target for encryption (may be)
       5.3 destination subfolder name. lets name it for example `dest` to speak definitively
       5.4 should private folder to be encrypted. 
       5.5 decryption options. it should contain all options neede for `mount -t ecryptfs ~/Private/ ~/Private` (keep in mind that `Private` name is configurable)
    lets config be *.json

6. algo:
   program reads config, for every folder (local folder) found in config it reads ssh destinations.
      for every destination it tries to open it using configured creds or ssh.
      after it opened ssh of destination it does the following:
          1. if destination/private folders do not exist - create them
          2. if encryption option in our *.json config is on then: 
                ensure that private folder is mounted and so is decrypted. if not: decrypt it using configured options, so dest folder to be prepared for rsync
          3. does rsync
          4. if encryption option in our *.json config is on then: 
               unmount private folder
